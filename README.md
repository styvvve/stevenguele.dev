# stevenguele.dev

Mon site personnel : portfolio pour ma recherche d'alternance et blog technique.

Le site est en cours de construction, je travaille sur la page d'accueil.

## Stack

- Astro 7 (site statique)
- CSS natif, avec des variables pour les couleurs
- Polices Inter et JetBrains Mono

## Lancer le projet

Il faut Node.js 22 ou plus.

```sh
npm install
npm run dev
```

Le site est ensuite accessible sur http://localhost:4321.

## Structure

```text
public/              favicons, cv.pdf
src/
  components/        Nav, Footer, Button
  layouts/           Base.astro
  pages/             index.astro
  styles/global.css
```
